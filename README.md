**VoiceMed** is a lightweight, privacy-minded healthcare decision-support prototype. It combines an **explainable local rule engine**, reviewed drug profiles, **Indian Rupee (₹ / INR) bill categorization**, browser document review, and speech input/playback. It does not use retrieval-augmented generation or a generative model for analysis.

---

> ### ⚠️ Critical Medical Disclaimer
> **VoiceMed** is a community-developed educational and clinical decision-support prototype. It is **not** a certified medical device, diagnostic system, or substitute for licensed medical judgment. Never disregard professional clinical advice or delay seeking emergency care based on outputs generated by this system. In medical emergencies in India, immediately call **108** or **112** (or **911** in the US).

## 🎯 The Problem Statement

Modern healthcare systems impose severe cognitive and financial burdens on patients due to four systemic breakdowns:

```
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                           CRITICAL HEALTHCARE SYSTEM DOWNFALLS                          │
├───────────────────────────────┬───────────────────────────────┬─────────────────────────┤
│ 1. Cryptic Prescription       │ 2. Opaque Hospital Billing    │ 3. Intimidating Policy  │
│    Shorthand                  │    & Consumable Markups       │    Jargon & Deductions  │
│ Doctors write in abbreviated  │ Hospital bills contain dense  │ IRDAI policies hide 1%  │
```

## 🚀 Key Medical Features

### 1. 💊 Prescription Decoding & Drug Safety (`"prescription"`)
- **Medical Shorthand Translation:** Translates physician abbreviations (`OD`, `BD`, `TID`, `QID`, `AC`, `PC`, `HS`, `SOS`, `1-0-1`, `PO`, `PRN`) into plain, actionable instructions.
- **Local formulary rules:** Exact-name and brand-name matching against `drugs.json`, with explicit shorthand decoding and safety notices. This is a deterministic lookup/rule engine, not RAG or generative AI.
- **Strict Food & Timing Directives:** Explains exact meal timings (e.g. taking PPIs 30–60 min before breakfast, taking NSAIDs after food to prevent gastric ulcers).

### 2. 🧾 Hospital Bill & Cost Breakdown in INR (`"bill_analysis"`)
- **Localized in Indian Rupees (₹ / INR):** Parses hospital bills, invoices, and estimates in Indian Rupees (₹, Rs., INR).
- **Itemized Categorization:** Groups receipts into 6 standardized buckets:
  1. *Room & Nursing Care* (e.g. Deluxe Room ₹10,000/day)
  2. *Doctor & Surgeon Consultation Fees* (e.g. ₹1,500/visit)
  3. *Diagnostic / Laboratory / Imaging* (e.g. CBC ₹800)
  4. *Pharmacy & IV Infusions* (e.g. IV Amox ₹480)
  5. *Operation Theatre & Surgical Procedures* (e.g. OT ₹8,400)
  6. *Non-Medical Consumables & Miscellaneous* (e.g. PPE & Gloves ₹3,250)
- **Consumable Markup Audit:** Flags high-margin disposable items often excluded by standard insurers under Non-Payable riders.
- **Patient Advocacy Guidance:** Provides actionable questions to challenge billing discrepancies against hospital tariff cards and GIPSA/ROHINI rates.

### 3. 🛡️ Health Insurance Clause Simplifier (`"insurance"`)
- **Plain-Language Demystification:** Translates dense legal clauses, pre-existing disease (PED) exclusions, and copayment percentages into understandable terms.
- **Room Rent Cap & Proportionate Deduction Alert:** Explicitly calculates the financial danger of selecting a room tier above policy limits (e.g. a 1% room rent cap breach triggering a 50% proportionate deduction across doctor and surgery fees).
- **TPA Pre-Authorization Checklist:** Step-by-step documentation guide to facilitate cashless claims and prevent rejections.

### 4. 🩺 Pocket Doctor & Preliminary Triage (`"pocket_doctor"`)
- **Urgency Triage Classification:** Categorizes patient queries into `EMERGENCY`, `URGENT`, `ROUTINE`, or `SELF_CARE`.
- **Red-Flag Symptom Detector:** Immediately triggers emergency warnings upon detecting acute chest pain, shortness of breath, neurological deficits, or severe trauma (advising calling 108 / 112 / 911).
- **Doctor Consultation Prep:** Formulates tailored questions for the patient's next clinical visit alongside supportive home comfort measures.

## 🖥️ Demo Dashboard & Document Workflow

- **Clinical Luxe interface:** Responsive dark clinical command center with high-contrast cyan/violet accents, animated VoiceMed branding, workspace navigation, tool cards, speech input, and a light/dark toggle.
- **Document intake:** The dashboard accepts text files, PDFs, and images. PDF text extraction and OCR run in the browser, with a 15 MB file-size and 20-page limit for the demo.
- **Scanned documents:** PDF.js renders scanned pages and Tesseract.js runs OCR in the browser. The PDF/image file itself is not sent to the backend; review extracted text before submitting it for analysis.
- **Explicit review consent:** Text analysis requires the user to confirm that extracted/pasted text was reviewed. Profile, recent activity, and saved explanations are held in page memory only and disappear when the page is closed or reloaded.
- **Report actions:** Download a Markdown summary, use the browser print dialog to save a PDF, or open WhatsApp with a prefilled message after confirming you want to share health information externally.
- **Browser libraries:** PDF/OCR processing loads PDF.js and Tesseract.js from public CDNs, so document intake requires internet access. Only the reviewed extracted text is sent to the local VoiceMed backend after confirmation. Optional ElevenLabs audio is available only through an explicit call to `/api/generate-audio`; analysis itself does not send the summary to the speech vendor.
- **Language limitation:** Rule-based written explanations are currently English. The language setting is used for browser speech input/playback where supported; it does not translate the written rules output.
- **Authentication limitation:** The sign-in and Google buttons are demo-only because no identity provider or account API is configured. Credentials are never sent or saved. “Remember this device” stores only the email address locally; patient profile details stay in page memory.

## ⚙️ Local Rule Engine

Analysis runs deterministically in the FastAPI process and does not require Ollama, an API key, or network access:

- **Prescription:** Exact local formulary/profile matching, shorthand decoding, and a conservative warning when allergy notes match a listed contraindication.
- **Hospital bills:** Keyword-based category assignment, INR amount parsing, and itemized review prompts. Parsed totals are estimates from lines recognized as line items; compare them with the original bill.
- **Insurance:** Explicit clause-keyword detection and a fixed checklist to review with the insurer. It does not decide coverage or calculate a claim outcome.
- **Triage:** Keyword-based urgency labels with a basic negation check and emergency warnings. It is not a diagnosis and should never replace emergency services or clinical judgement.

This rules-based prototype is intentionally transparent and limited: unknown language, OCR mistakes, uncommon terms, and context can result in missed or incorrect matches. Verify outputs against the original document and a qualified professional.

## 🎙️ Optional Audio Output (ElevenLabs + Web Speech)

Analysis responses include browser speech-synthesis instructions and do not make an external audio request. The dedicated `/api/generate-audio` endpoint can optionally request ElevenLabs when an API key is configured; otherwise it returns browser speech-synthesis instructions.

```mermaid
flowchart LR
    A[Text / Medical Summary] --> B{ELEVENLABS_API_KEY Available?}
    B -- Yes --> C[ElevenLabs Multilingual V2 API]
    C -- Success (200 OK) --> D[Base64 MP3 Audio Stream]
    C -- Failure / Timeout / Rate Limit --> E[Web Speech API Fallback Payload]
    B -- No / Unset --> E
    E --> F[Browser Native SpeechSynthesis\nwindow.speechSynthesis.speak]
    F --> G[Instant Voice Output\nTelugu, Hindi, English, Spanish]
```

- **Optional external voice:** If `ELEVENLABS_API_KEY` is configured, an explicit request to `/api/generate-audio` can synthesize speech through ElevenLabs Multilingual V2.
- **Browser voice:** The frontend can use `window.speechSynthesis` for speech playback. Voice availability depends on the browser and installed voices; it is not guaranteed to work offline.

## 💻 Tech Stack

| Component | Technology | Description |
| :--- | :--- | :--- |
| **API Framework** | [FastAPI](https://fastapi.tiangolo.com/) | High-performance async Python backend with interactive API schema docs |
| **ASGI Server** | [Uvicorn](https://www.uvicorn.org/) | Production-ready ASGI server |
| **Data Validation** | [Pydantic v2](https://docs.pydantic.dev/) | Strict typing, schema validation, and serialization |
| **Analysis engine** | Python deterministic rules | Local formulary matching, shorthand, bill categorization, insurance keywords, triage rules |
| **Document extraction** | PDF.js + Tesseract.js | Browser-side PDF text extraction and OCR; internet required to load libraries |
| **Voice** | Browser Speech APIs; optional ElevenLabs endpoint | Browser speech for user-triggered voice; ElevenLabs is not called by analysis |
| **Real-time Protocol** | WebSockets | Bidirectional low-latency streaming for live audio/OCR feeds |
| **Local formulary** | JSON (`drugs.json`) | Reviewed drug profile data used by exact matching rules |

## ⚡ Quickstart & Installation

### Prerequisites

- **Python**: 3.10 or higher
- **OS**: Windows 10/11, macOS, or Linux
- *(Optional)* **ElevenLabs API Key**: Set `ELEVENLABS_API_KEY` in environment for studio TTS.

### 1. Clone the Repository

```bash
git clone https://github.com/flashvenkat/CircuitHealth-AI.git voicemed-open
cd voicemed-open
```

### 2. Install Python Dependencies (System Python)

**On Windows (PowerShell):**
```powershell
python -m pip install --user -r requirements.txt
```

**On Linux / macOS:**
```bash
python3 -m pip install --user -r requirements.txt
```

These commands install packages for your user account using the system Python; they do not create or activate a virtual environment.

### 3. Start the Server

**Using the Windows launcher:**
```powershell
.\start_server.bat
```

**Or with Uvicorn:**
```bash
python -m uvicorn server:app --reload --host 127.0.0.1 --port 8000
```

The server will be available at:
- **API Base:** `http://127.0.0.1:8000`
- **Interactive Swagger Docs:** `http://127.0.0.1:8000/docs`
- **ReDoc Documentation:** `http://127.0.0.1:8000/redoc`

### 4. Run the Automated Test Client

```bash
python test_client.py
```
